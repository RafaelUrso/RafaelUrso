## 📌 Featured Projects

**[Plataforma de Analytics Conversacional (NL2SQL)](https://github.com/RafaelUrso/fuel-analytics-platform)**
Pipeline analítico onde o usuário pergunta em português, um agente traduz para SQL, consulta o data warehouse e devolve resposta com gráfico. PostgreSQL + Python + dbt + Dagster, agente construído com a API da Anthropic, dados públicos do IBGE e dados.gov.br.

**[Assistente de Estudos com IA](https://github.com/RafaelUrso/study-assistant)**
Pipeline de ETL sobre conteúdo não estruturado: extração de PDFs (pdfplumber), embeddings e indexação vetorial (ChromaDB), recuperação aumentada por LLM (RAG) via API da Anthropic, interface em Streamlit.

**[Albergue Sr. Almeida — Sistema de Reservas](https://github.com/RafaelUrso/Albergue)**
Sistema web completo de gestão de reservas (Next.js, Prisma, Auth.js, PostgreSQL), com 62 regras de negócio levantadas a partir de entrevistas com o cliente.
